# ♻️ RECYZA – AI Powered E-Commerce & Recycling Platform

RECYZA is an AI-powered e-commerce application that combines online shopping with smart recycling. Users can purchase products, recycle eligible plastic products, verify them using an image classification model, and earn rewards.

## 🚀 Features

- 🛍️ E-commerce shopping interface
- 🛒 Add to Cart & Demo Checkout
- 📦 My Orders section
- ♻️ Recycle Product option
- 🤖 AI Image Classification (10 product classes)
- 💰 Money Credit rewards
- 🪙 SuperCoins reward system
- 🌱 Sustainable shopping experience

## 🧠 AI Model

- Framework: TensorFlow / Keras
- Image Size: 224 × 224
- Classes: 10
- Test Accuracy: **95.16%**

```bash

```

## ♻️ RECYZA Workflow

Shop → Add to Cart → Place Order → My Orders → Recycle Product → Upload Image → AI Verification → Earn Rewards

## 📊 Project Outcome

RECYZA demonstrates how Artificial Intelligence, E-commerce, and Recycling can work together to encourage responsible consumption and build a sustainable future.
